# Privacy Policy — Client Progress Report

_Last updated: 12 November 2026_

This plugin is a set of instructions (skills) that runs inside Claude. It has no servers of its own.

- **No data collection.** The plugin author does not receive, store or process any repository data, reports or other content.
- **What the plugin reads.** Through the GitHub access you have connected in Claude (or `gh`/`git` in Claude Code), Claude reads repository activity you point it to: pull requests, commits, issues and releases. This can include contributors' GitHub usernames. It happens inside your Claude session under Anthropic's terms and privacy policy and GitHub's terms.
- **No storage, no third parties.** Nothing is stored or sent anywhere by the plugin; reports stay in your conversation.
- **No tracking, cookies or analytics** are added by the plugin.

Questions: https://github.com/xelA31B/client-progress-report/issues
